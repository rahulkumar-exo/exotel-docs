# Services Provided by Exotel

Exotel offers a comprehensive suite of cloud communication services designed to help businesses manage customer interactions efficiently. Here is an overview of all the services available.

## Voice Services

### Incoming Calls

Handle incoming calls with configurable call flows, IVR menus, call routing, and queuing.

- Route calls to the right department or agent
- Play greetings and IVR menus
- Queue callers when agents are busy
- Record calls for quality assurance
- Track call analytics in real time

See: [How to Make or Receive Calls](/docs/call-support/call-features/make-receive-calls)

### Outgoing Calls

Make outbound calls to customers using APIs or the dashboard. The customer sees your ExoPhone as the caller ID, protecting agent privacy.

- Click-to-call from your CRM or application
- Automated calls triggered by events
- Connect two numbers via API

See: [Outgoing Calls](/docs/call-support/call-features/outgoing-calls) | [Voice v1 API](/docs/voice-v1/overview)

### IVR (Interactive Voice Response)

Build interactive phone menus that let callers self-serve or route themselves to the right team.

- Single-level and multi-level IVR
- DTMF input collection
- Dynamic routing based on caller input

See: [IVR Setup](/docs/call-support/call-features/ivr-setup) | [Multi-Level IVR](/docs/call-support/advanced-features/multi-level-ivr)

### Call Recording

Record incoming and outgoing calls for quality assurance, training, and compliance.

See: [Call Recording](/docs/call-support/call-features/call-recording)

### Number Masking

Connect two parties (e.g., delivery agent and customer) without revealing personal phone numbers.

See: [Number Masking](/docs/call-support/advanced-features/number-masking)

## SMS Services

### Transactional SMS

Send automated SMS messages for OTPs, order confirmations, appointment reminders, and other transactional use cases.

See: [SMS API](/docs/sms-api/overview)

### Promotional SMS

Send promotional messages and marketing campaigns to opted-in customers.

### Bulk SMS

Send the same or different messages to large lists of recipients.

See: [Bulk SMS API](/docs/sms-api/api-reference/bulk-sms)

## Campaign Services

### Voice Campaigns

Run automated outbound calling campaigns to a list of phone numbers. Campaigns support IVR flows, retries, scheduling, and reporting.

See: [Campaigns API](/docs/campaigns/overview)

### SMS Campaigns

Send bulk SMS campaigns with scheduling, DLT compliance, and delivery tracking.

See: [SMS Campaigns API](/docs/sms-campaigns/overview)

## Contact Center

### Cloud Contact Center

A full-featured contact center solution for managing inbound and outbound call center operations.

- Agent management and presence
- Call distribution and queuing
- Supervisor monitoring
- Call dispositions and wrap-up
- Real-time dashboards

See: [Contact Center API](/docs/contact-center/overview)

## Advanced Services

### Exotel Flow Builder

A visual drag-and-drop tool for building complex call flows without writing code.

See: [Flow Builder](/docs/call-support/advanced-features/flow-builder)

### Smart Routing

Dynamic call routing based on caller data, time of day, agent skills, or API responses.

See: [Smart Routing](/docs/call-support/advanced-features/smart-routing)

### Truecaller Verified Business Caller ID

Display your verified business name on the caller's phone when making outbound calls via Truecaller.

See: [Truecaller Verified Caller ID](/docs/call-support/advanced-features/truecaller-verified-caller-id)

### WhatsApp Business API

Send and receive WhatsApp messages for customer support, notifications, and marketing.

See: [WhatsApp API](/docs/whatsapp-api/overview)
