# Bulk SMS

Send the same message to multiple recipients, or unique messages to different recipients in a single API call.

---

## Static Bulk SMS (Same Message)

Send an identical message to multiple phone numbers in one request. Uses the same endpoint as Send SMS — pass `To` as a repeated array parameter.

<TryItBanner method="POST" endpoint="/v1/Accounts/{sid}/Sms/send" />

<RegionalUrls path="/v1/Accounts/{account_sid}/Sms/send" host="api" />

### Parameters

All [Send SMS](/docs/sms-api/api-reference/send-sms) parameters apply. The key difference is `To`, which must be passed as an array:

| Parameter | Required  | Description |
|-----------|-----------|-------------|
| `From`    | Mandatory | ExoPhone or approved Sender ID |
| `To[]`    | Mandatory | Repeat this parameter for each recipient number |
| `Body`    | Mandatory | Message content (max 2000 characters) |

### Examples

<Tabs groupId="programming-language">
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://<api_key>:<api_token><subdomain>/v1/Accounts/<your_sid>/Sms/send \
  -d "From=0XXXXXX4890" \
  -d "To[]=+919876543210" \
  -d "To[]=+919876543211" \
  -d "Body=Flash sale! 50% off all items today." \
  -d "DltEntityId=1234567890"
```

</TabItem>
<TabItem value="python" label="Python">

```python
    ('To[]', '+919876543211'),

    ('DltEntityId', '1234567890'),
]

response = requests.post(
    'https://<api_key>:<api_token><subdomain>/v1/Accounts/<your_sid>/Sms/send',
    data=data
)

print(response.json())
```

## Dynamic Bulk SMS (Unique Messages)

Send personalized messages to different recipients in a single request. Uses the `/bulksend` endpoint with form-encoded `Messages[]` array. Maximum **100 messages per request**.

<TryItBanner method="POST" endpoint="/v1/Accounts/{sid}/Sms/bulksend" />

<RegionalUrls path="/v1/Accounts/{account_sid}/Sms/bulksend" host="api" />

### Parameters

| Parameter | Required | Description |
|-----------|----------|-------------|
| `From` | Optional | Default ExoPhone or Sender ID. Used when `From` is not set in a `Messages` entry. |
| `Messages` | Mandatory | Array of message objects (max 100). Each object must include `To` and `Body`. |
| `Messages[N][To]` | Mandatory | Recipient number for message N |
| `Messages[N][Body]` | Mandatory | Message content for message N (max 2000 chars) |
| `Messages[N][From]` | Optional | Per-message Sender ID; falls back to outer `From` |
| `Messages[N][SmsType]` | Optional | Per-message SMS type: `transactional`, `transactional_opt_in`, `promotional` |
| `Messages[N][DltTemplateId]` | Optional | Per-message DLT Template ID (India) |
| `EncodingType` | Optional | `plain` or `unicode` |
| `ShortenUrl` | Optional | `true` to shorten URLs |
| `ShortenUrlParams[Header]` | Optional | DLT-registered header for the short URL domain |
| `ShortenUrlParams[Tracking]` | Optional | `true` to enable click tracking |
| `ShortenUrlParams[ClickTrackingCallbackUrl]` | Optional | Webhook URL for click events |
| `StatusCallback` | Optional | URL to receive delivery status per message |
| `DltEntityId` | Optional (Mandatory for India) | DLT Entity ID applied to all messages |
| `CustomField` | Optional | Custom reference field |
| `Priority` | Optional | `normal` or `high` |

## Limits

| Limit | Value |
|-------|-------|
| Max recipients — static bulk | 100 numbers |
| Max messages — dynamic bulk | 100 messages |
| API error code | 40406 (static) / 40400 (dynamic) if exceeded |

:::note
Each message in a bulk request is processed independently. Individual messages may succeed or fail without affecting others.
:::
