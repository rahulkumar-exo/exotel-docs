# SMS Details

Retrieve the details and delivery status of a specific SMS message.

<TryItBanner method="GET" endpoint="/v1/Accounts/{sid}/SMS/Messages/{SmsSid}" />

<RegionalUrls path="/v1/Accounts/{account_sid}/SMS/Messages/{SmsSid}" host="api" />

## Path Parameters

| Parameter  | Required  | Description |
|------------|-----------|-------------|
| `SmsSid`   | Mandatory | The unique SMS identifier returned when the message was sent |

## Response Fields

| Field                | Type     | Description |
|----------------------|----------|-------------|
| `Sid`                | String   | Unique SMS identifier |
| `Status`             | String   | High-level status: `queued`, `sending`, `submitted`, `sent`, `failed`, `failed-dnd` |
| `DetailedStatusCode` | Integer  | Numeric status code (see [Status Codes](/docs/sms-api/api-reference/status-codes)) |
| `DetailedStatus`     | String   | Human-readable status description |
| `DateCreated`        | DateTime | When the request was received |
| `DateSent`           | DateTime | When the SMS was sent to the operator |
| `DateUpdated`        | DateTime | Last status update timestamp |
| `Price`              | Double   | Amount charged |

## Error Codes

| HTTP Code | API Error Code | Scenario |
|-----------|---------------|----------|
| 200 | — | SID not found — returns `"No matching results"` (not a 404) |
| 429 | 40403 | Too many GET requests |
| 400 | 40501 | Invalid parameters in the request URL |
| 403 | 40002 | Account inactive |
| 401 | — | Auth key or token missing |
| 401 | 34010 | Invalid auth key or token |
| 403 | 34009 | Account SID missing or action forbidden on resource |

:::note
A `200` response with `"No matching results"` means the SID was not found — this is not an error HTTP status code.
:::
