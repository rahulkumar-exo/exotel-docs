# Contact Center APIs v4

:::caution Legacy Version
Contact Center APIs v4 is the older version. For new integrations, please use the [Contact Center API (v2/CCM)](/docs/contact-center/overview).
:::

Contact Center APIs v4 provides call management capabilities for contact center operations. These APIs integrate with the Exotel dashboard for agent and call management.

## Key Features

- Agent-to-customer call connections
- Call recording and monitoring
- Queue management
- Real-time status updates

## Migration

If you're currently using v4, we recommend migrating to the latest Contact Center API for:
- Improved performance and reliability
- Enhanced status callback support
- Better agent device management
- SIP integration support

See the [Contact Center API](/docs/contact-center/overview) documentation for the latest version.
