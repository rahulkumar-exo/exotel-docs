# SIP Trunking

Connect your PBX, SBC, or SIP platform to Exotel's PSTN network. Create trunks, map numbers, and route inbound/outbound calls with REST APIs.

```
Outbound:  Your SIP → Exotel trunk → PSTN
Inbound:   PSTN → Exotel → Flow (Connect) → trunk → Your SIP
```
