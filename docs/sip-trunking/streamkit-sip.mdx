# StreamKit Cloud SIP trunking setup

Use Dynamic SIP Trunking so your contact centre can send SIP to Exotel, and StreamKit bridges media to your AgentStream WebSocket bot.

```
Customer → CC (SIP) → Exotel StreamKit → AgentStream WSS ↔ bot
```

Full narrative walkthrough (headers, Passthru escalate, modes): [StreamKit Cloud SIP trunking setup](https://docs.exotel.com/dynamic-sip-trunking/streamkit-cloud-sip-trunking-setup) on the docs portal. AgentStream bridge overview: [StreamKit Cloud](/docs/agentstream/streamkit-cloud).

Map the phone number with `"mode": "flow"` for Voicebot / StreamKit App Bazaar journeys. For Connect-to-SIP only, use `pstn`. See [Call directions](./call-directions).

---

## Step 1 — Create trunk

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks" />

<RegionalUrls path="/v2/accounts/{account_sid}/trunks" host="api" />

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `trunk_name` | Yes | String | Alphanumeric + underscores, max 16 chars |
| `nso_code` | Yes | String | Use `"ANY-ANY"` |
| `domain_name` | Yes | String | `{account_sid}.pstn.exotel.com` |

## Step 3a — Whitelist IP (outbound)

Required when your system has a static egress IP.

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks/{trunk_sid}/whitelisted-ips" />

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `ip` | Yes | String | Public IPv4 of your SBC / PBX |
| `mask` | No | Integer | CIDR mask (default `32`) |

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/whitelisted-ips" \
  -H "Content-Type: application/json" \
  -d '{ "ip": "<your_public_ip>", "mask": 32 }'
```

## Step 3b — Digest credentials (optional)

Use for cloud platforms with dynamic IPs. You can use ACL, credentials, or both.

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks/{trunk_sid}/credentials" />

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `user_name` | Yes | String | SIP digest username |
| `password` | Yes | String | Strong password |
| `friendly_name` | No | String | Label, max 32 chars |

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/credentials" \
  -H "Content-Type: application/json" \
  -d '{
    "user_name": "SIP_USER",
    "password": "SIP_PASS",
    "friendly_name": "voice_ai_platform"
  }'
```

## Step 5 — App Bazaar flow + VoIP Exophone

1. Build a flow: Greeting (recommended) → Voicebot or Stream → optional Passthru / Connect  
2. Map your VoIP Exophone to that flow  

Deep how-to: [StreamKit Cloud SIP trunking setup](https://docs.exotel.com/dynamic-sip-trunking/streamkit-cloud-sip-trunking-setup) · AgentStream overview: [StreamKit Cloud](/docs/agentstream/streamkit-cloud)
