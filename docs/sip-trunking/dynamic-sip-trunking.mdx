# Dynamic SIP Trunking API

**SIP Trunking** is the product that connects your PBX, SBC, or SIP platform to Exotel PSTN.  
**Dynamic SIP Trunking** is the REST API used to create and manage those trunks.

Use these APIs to make outbound calls (SIP → PSTN), receive inbound calls (PSTN → SIP), and integrate with Exotel Flows / StreamKit Voice AI.

**Samples:** [Postman](https://www.postman.com/grey-star-272776/exotel-sip-trunking-apis/collection/14803574-a0c66128-0e2c-4e6d-a06a-03173b9d43cd) · [GitHub](https://github.com/exotel/exotel-vsip-trunk-configuration-api/tree/main)

---

## Base URL and authentication

All APIs use HTTP Basic Auth. Prefix every path with `/v2/accounts/{account_sid}`.

| Region | Base URL |
|--------|----------|
| India (Mumbai) | `https://api.in.exotel.com` |
| Singapore | `https://api.exotel.com` |

| Header | Value |
|--------|-------|
| `Authorization` | Basic (`api_key`:`api_token`) |
| `Content-Type` | `application/json` |

**Rate limit:** 200 requests/minute.

```bash
export EXOTEL_API_KEY="your_api_key"
export EXOTEL_API_TOKEN="your_api_token"
export EXOTEL_ACCOUNT_SID="your_account_sid"
export EXOTEL_SUBDOMAIN="api.in.exotel.com"   # or api.exotel.com
```

### Response envelope

Successful calls return this shape (field names exact):

```json
{
  "request_id": "10a67da360d446378d5c2b66407b7f18",
  "method": "POST",
  "http_code": 200,
  "response": {
    "code": 200,
    "error_data": null,
    "status": "success",
    "data": { }
  }
}
```

List endpoints wrap items in `response[]` and may include `metadata` (`page_size`, `first_page_uri`, `prev_page_uri`, `next_page_uri`).

## Workflow

```
Create trunk → Map phone-numbers → whitelisted-ips and/or credentials → destination-uris
```

| Direction | Requires |
|-----------|----------|
| Outbound | Trunk + mapped DID + ACL and/or digest credentials |
| Inbound | `destination-uris` + Connect applet `sip:<trunk_sid>` |

Number `mode`: `pstn` (default) · `flow` (Voice AI / StreamKit). See [Call directions](./call-directions).

## Setup APIs

### Create trunk

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks" />

<RegionalUrls path="/v2/accounts/{account_sid}/trunks" host="api" />

#### Request parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `trunk_name` | Yes | String | Alphanumeric + underscores only, max 16 chars |
| `nso_code` | Yes | String | Use `"ANY-ANY"` |
| `domain_name` | Yes | String | `{account_sid}.pstn.exotel.com` |

#### Example request

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks" \
  -H "Content-Type: application/json" \
  -d '{
    "trunk_name": "outbound_trunk",
    "nso_code": "ANY-ANY",
    "domain_name": "'"$EXOTEL_ACCOUNT_SID"'.pstn.exotel.com"
  }'
```

#### Example response

```json
{
  "request_id": "10a67da360d446378d5c2b66407b7f18",
  "method": "POST",
  "http_code": 200,
  "response": {
    "code": 200,
    "error_data": null,
    "status": "success",
    "data": {
      "trunk_sid": "trmum1f708622631150902801a1n",
      "trunk_name": "outbound_trunk",
      "status": "active",
      "domain_name": "ameyo5m.pstn.exotel.com",
      "auth_type": "IP-WHITELIST",
      "nso_code": "ANY-ANY",

      "whitelisted_ips": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/whitelisted-ips",
      "destination_uris": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/destination-uris",
      "credentials": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/credentials"

}
```

Save `response.data.trunk_sid`. Nested resource URLs in the response already use hyphenated paths — reuse them as-is.

### Map destination URI — inbound

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks/{trunk_sid}/destination-uris" />

#### Request parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `destinations` | Yes | Array | List of destination objects |
| `destinations[].destination` | Yes | String | `<ip_or_fqdn>:<port>;transport=tls` or `tcp` |

Prefer TLS on port `5061`.

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/destination-uris" \
  -H "Content-Type: application/json" \
  -d '{
    "destinations": [
      { "destination": "44.248.146.11:5061;transport=tls" }
    ]
  }'
```

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/destination-uris" \
  -H "Content-Type: application/json" \
  -d '{
    "destinations": [
      { "destination": "sip.yourcompany.com:5061;transport=tls" }
```
