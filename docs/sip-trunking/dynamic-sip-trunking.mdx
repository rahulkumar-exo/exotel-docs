# Dynamic SIP Trunking API

**SIP Trunking** is the product that connects your PBX, SBC, or SIP platform to Exotel PSTN.  
**Dynamic SIP Trunking** is the REST API used to create and manage those trunks.

Use these APIs to make outbound calls (SIP → PSTN), receive inbound calls (PSTN → SIP), and integrate with Exotel Flows / StreamKit Voice AI.

**Samples:** [Postman](https://www.postman.com/grey-star-272776/exotel-sip-trunking-apis/collection/14803574-a0c66128-0e2c-4e6d-a06a-03173b9d43cd) · [GitHub](https://github.com/exotel/exotel-vsip-trunk-configuration-api/tree/main)

---

## Base URL and authentication

All APIs use HTTP Basic Auth. Prefix every path with `/v2/accounts/{account_sid}`.

| Region | Base URL |
|--------|----------|
| India (Mumbai) | `https://api.in.exotel.com` |
| Singapore | `https://api.exotel.com` |

| Header | Value |
|--------|-------|
| `Authorization` | Basic (`api_key`:`api_token`) |
| `Content-Type` | `application/json` |

**Rate limit:** 200 requests/minute.

```bash
export EXOTEL_API_KEY="your_api_key"
export EXOTEL_API_TOKEN="your_api_token"
export EXOTEL_ACCOUNT_SID="your_account_sid"
export EXOTEL_SUBDOMAIN="api.in.exotel.com"   # or api.exotel.com
```

### Response envelope

Successful calls return this shape (field names exact):

```json
{
  "request_id": "10a67da360d446378d5c2b66407b7f18",
  "method": "POST",
  "http_code": 200,
  "response": {
    "code": 200,
    "error_data": null,
    "status": "success",
    "data": { }
  }
}
```

List endpoints wrap items in `response[]` and may include `metadata` (`page_size`, `first_page_uri`, `prev_page_uri`, `next_page_uri`).

## Workflow

```
Create trunk → Map phone-numbers → whitelisted-ips and/or credentials → destination-uris
```

| Direction | Requires |
|-----------|----------|
| Outbound | Trunk + mapped DID + ACL and/or digest credentials |
| Inbound | `destination-uris` + Connect applet `sip:<trunk_sid>` |

Number `mode`: `pstn` (default) · `flow` (Voice AI / StreamKit). See [Call directions](./call-directions).

## Endpoint index

Paths below are relative to `/v2/accounts/{account_sid}`.

### Setup

| Method | Path | Purpose |
|--------|------|---------|
| `POST` | `/trunks` | Create trunk |
| `POST` | `/trunks/{trunk_sid}/phone-numbers` | Map DID |
| `POST` | `/trunks/{trunk_sid}/whitelisted-ips` | Add ACL |
| `POST` | `/trunks/{trunk_sid}/credentials` | Create digest credentials |
| `POST` | `/trunks/{trunk_sid}/destination-uris` | Map inbound URI |

### Manage & view

| Method | Path | Purpose |
|--------|------|---------|
| `GET` | `/trunks` | List trunks |
| `PUT` | `/trunks/{trunk_sid}` | Update trunk |
| `DELETE` | `/trunks?trunk_sid=` | Delete trunk |
| `GET` | `/trunks/{trunk_sid}/phone-numbers` | List mapped numbers |
| `PUT` | `/trunks/{trunk_sid}/phone-numbers/{id}` | Update `mode` |
| `DELETE` | `/trunks/{trunk_sid}/phone-numbers?id=` | Unmap number |
| `GET` | `/trunk-maps?exophone=` | Lookup DID → trunk |
| `GET` | `/trunks/{trunk_sid}/whitelisted-ips` | List ACLs |
| `PUT` | `/trunks/{trunk_sid}/whitelisted-ips/{id}` | Update ACL |
| `DELETE` | `/trunks/{trunk_sid}/whitelisted-ips?id=` | Delete ACL |
| `GET` | `/trunks/{trunk_sid}/destination-uris` | List URIs |
| `PUT` | `/trunks/{trunk_sid}/destination-uris/{id}` | Update priority/weight |
| `DELETE` | `/trunks/{trunk_sid}/destination-uris?id=` | Delete URI |
| `GET` | `/trunks/{trunk_sid}/credentials` | List credentials |
| `PUT` | `/trunks/{trunk_sid}/credentials/{id}` | Update credential |
| `DELETE` | `/trunks/{trunk_sid}/credentials?id=` | Delete credential |

| `POST` | `/trunks/{trunk_sid}/settings` | Set caller ID alias |
| `DELETE` | `/trunks/{trunk_sid}/settings?name=` | Delete setting |

## Setup APIs

### Create trunk

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks" />

<RegionalUrls path="/v2/accounts/{account_sid}/trunks" host="api" />

#### Request parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `trunk_name` | Yes | String | Alphanumeric + underscores only, max 16 chars |
| `nso_code` | Yes | String | Use `"ANY-ANY"` |
| `domain_name` | Yes | String | `{account_sid}.pstn.exotel.com` |

#### Example request

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks" \
  -H "Content-Type: application/json" \
  -d '{
    "trunk_name": "outbound_trunk",
    "nso_code": "ANY-ANY",
    "domain_name": "'"$EXOTEL_ACCOUNT_SID"'.pstn.exotel.com"
  }'
```

#### Example response

```json
{
  "request_id": "10a67da360d446378d5c2b66407b7f18",
  "method": "POST",
  "http_code": 200,
  "response": {
    "code": 200,
    "error_data": null,
    "status": "success",
    "data": {
      "trunk_sid": "trmum1f708622631150902801a1n",
      "trunk_name": "outbound_trunk",
      "status": "active",
      "domain_name": "ameyo5m.pstn.exotel.com",
      "auth_type": "IP-WHITELIST",
      "nso_code": "ANY-ANY",
      "phone_numbers": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/phone-numbers",
      "whitelisted_ips": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/whitelisted-ips",
      "destination_uris": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/destination-uris",
      "credentials": "/v2/accounts/ameyo5m/trunks/trmum1f708622631150902801a1n/credentials"
    }
  }
}
```

:::note
Save `response.data.trunk_sid`. Nested resource URLs in the response already use hyphenated paths — reuse them as-is.
:::

### Map phone number

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks/{trunk_sid}/phone-numbers" />

#### Request parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `phone_number` | Yes | String | E.164 (`+919876543210`) |
| `mode` | No | String | `pstn` (default) or `flow` (StreamKit / Voice AI) |

#### Example request

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/phone-numbers" \
  -H "Content-Type: application/json" \
  -d '{
    "phone_number": "+919876543210",
    "mode": "pstn"
  }'
```

#### Example response (`data`)

```json
{
  "id": "41512",
  "phone_number": "+919876543210",
  "trunk_sid": "trmum1f708622631150902801a1n",
  "mode": "pstn",
  "date_created": "2026-01-23T10:26:54Z",
  "date_updated": "2026-01-23T10:26:54Z"
}
```

:::note
Save numeric mapping `id` for update/delete. Do not pass the E.164 string as the path id.
:::

### Create SIP digest credentials — outbound

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks/{trunk_sid}/credentials" />

#### Request parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `user_name` | Yes | String | SIP digest username |
| `password` | Yes | String | Strong password |
| `friendly_name` | No | String | Label, max 32 chars |

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/credentials" \
  -H "Content-Type: application/json" \
  -d '{
    "user_name": "SIP_USER",
    "password": "strong_password_here",
    "friendly_name": "voice_ai_prod"
  }'
```

| Scenario | Auth |
|----------|------|
| Fixed-IP PBX / SBC | `whitelisted-ips` |
| Dynamic cloud egress | `credentials` |
| High security | Both |

### Map destination URI — inbound

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/trunks/{trunk_sid}/destination-uris" />

#### Request parameters

| Parameter | Required | Type | Description |
|-----------|----------|------|-------------|
| `destinations` | Yes | Array | List of destination objects |
| `destinations[].destination` | Yes | String | `<ip_or_fqdn>:<port>;transport=tls` or `tcp` |

Prefer TLS on port `5061`.

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/destination-uris" \
  -H "Content-Type: application/json" \
  -d '{
    "destinations": [
      { "destination": "44.248.146.11:5061;transport=tls" }
    ]
  }'
```

```bash
curl -s -u "$EXOTEL_API_KEY:$EXOTEL_API_TOKEN" -X POST \
  "https://$EXOTEL_SUBDOMAIN/v2/accounts/$EXOTEL_ACCOUNT_SID/trunks/<trunk_sid>/destination-uris" \
  -H "Content-Type: application/json" \
  -d '{
    "destinations": [
      { "destination": "sip.yourcompany.com:5061;transport=tls" }
    ]
  }'
```

Save destination `id` from `response.data` for update/delete. Inbound Connect applet: [Connect Applet inbound](./connect-applet-inbound).
