# Bot stream with Legs API

Start a bidirectional AgentStream session from Legs actions — with an optional greeting while the bot warms up.

For the full outbound/inbound ExoML path, see [Programmable Voice with AgentStream](./programmable-voice).

## Patterns

| Goal | Pattern |
|------|---------|
| Bot-first / tech support | `leg_answered` → `StartStream` |
| Sales / collections (no dead air) | `leg_answered` → `StartStream` + `Say` → on `stream_started` → `StopSay` |
| Per-call stream URL | Decide `streamUrl` in your service at runtime |

## Authentication

HTTP Basic Auth. `Content-Type: application/json`

**Base URL:** `https://cpaas-api.in.exotel.com/v2/accounts/{account_sid}`

---

## Actions

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/legs/{leg_sid}/actions" />

<RegionalUrls path="/v2/accounts/{account_sid}/legs/{leg_sid}/actions" host="cpaas" />

Post JSON with an `exoml` field. The ExoML string is an XML document with a `<Flow>` root element.

---

### Start stream

Starts a bidirectional audio stream to your bot's WebSocket.

```bash
curl -u '<api_key>:<api_token>' -X POST \
  'https://cpaas-api.in.exotel.com/v2/accounts/<account_sid>/legs/<leg_sid>/actions' \
  -H 'Content-Type: application/json' \
  -d '{"exoml": "<Flow><StartStream streamUrl=\"wss://bot.example.com/stream\" streamType=\"bidirectional\"/></Flow>"}'
```

| Attribute | Required | Description |
|-----------|----------|-------------|
| `streamUrl` | Yes | Bot WebSocket URL |
| `streamType` | Yes | `bidirectional` or `unidirectional` |

---

### Say

Plays text-to-speech audio on the leg while the bot warms up.

```bash
curl -u '<api_key>:<api_token>' -X POST \
  'https://cpaas-api.in.exotel.com/v2/accounts/<account_sid>/legs/<leg_sid>/actions' \
  -H 'Content-Type: application/json' \
  -d '{"exoml": "<Flow><Say language=\"en\">Connecting you now.</Say></Flow>"}'
```

| Attribute | Required | Description |
|-----------|----------|-------------|
| `language` | No | BCP-47 language code (e.g. `en`). Default: `en`. |
| `preferredTTSEngine` | No | TTS engine preference (e.g. `polly`, `googletts`) |
| `loop` | No | Repeat count. Default: `0` (play once). |

---

### StopSay

Stops any in-progress `Say` playback.

```bash
curl -u '<api_key>:<api_token>' -X POST \
  'https://cpaas-api.in.exotel.com/v2/accounts/<account_sid>/legs/<leg_sid>/actions' \
  -H 'Content-Type: application/json' \
  -d '{"exoml": "<Flow><StopSay/></Flow>"}'
```

## After stream starts

Your bot receives the same [WebSocket protocol](./websocket-protocol) events as Voicebot applet sessions.
