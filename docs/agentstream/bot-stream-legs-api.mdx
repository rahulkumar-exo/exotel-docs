# Bot stream with Legs API

Start a bidirectional AgentStream session from Legs actions — with an optional greeting while the bot warms up.

For the full outbound/inbound ExoML path, see [Programmable Voice with AgentStream](./programmable-voice).

## Patterns

| Goal | Pattern |
|------|---------|
| Bot-first / tech support | `leg_answered` → `StartStream` |
| Sales / collections (no dead air) | `leg_answered` → `StartStream` + `Say` → on `stream_started` → `StopSay` |
| Per-call stream URL | Decide `streamUrl` in your service at runtime |

## Authentication

HTTP Basic Auth. `Content-Type: application/json`

**Base URL:** `https://cpaas-api.in.exotel.com/v2/accounts/{account_sid}`  
(Singapore: `cpaas-api.exotel.com`)

---

## Start stream

Every leg action uses one endpoint, `POST /v2/accounts/{account_sid}/legs/{leg_sid}/actions`. The action is ExoML in the `exoml` field of the JSON body. There are no per-action paths such as `/actions/start_stream` or `/actions/start_say`; those return 404.

<TryItBanner method="POST" endpoint="/v2/accounts/{account_sid}/legs/{leg_sid}/actions" />

<RegionalUrls path="/v2/accounts/{account_sid}/legs/{leg_sid}/actions" host="cpaas" />

### Request body

| Field | Required | Type | Description |
|-------|----------|------|-------------|
| `exoml` | Yes | String | ExoML document: a `<Flow>` with the action verb |
| `action_custom_param` | No | String | Your reference; returned in the events for this action |

### `StartStream` attributes

| Attribute | Required | Description |
|-----------|----------|-------------|
| `streamType` | Yes | `bidirectional` for Voice AI bots; `unidirectional` sends call audio only |
| `streamUrl` | Yes | Bot WebSocket URL (`wss://`). Up to 25 custom query parameters, 800 characters in total; write `&` as `&amp;` |
| `sourceDirection` | No | `in`, `out` or `both` (default). Unidirectional streams only |
| `secureDtmf` | No | `true` sends caller DTMF encrypted. Bidirectional streams only; share your CA certificate with Exotel first |

### Example request

```bash
curl -u '<api_key>:<api_token>' -X POST \
  'https://cpaas-api.in.exotel.com/v2/accounts/<account_sid>/legs/<leg_sid>/actions' \
  -H 'Content-Type: application/json' \
  -d '{
    "action_custom_param": "bot-stream",
    "exoml": "<?xml version=\"1.0\" encoding=\"UTF-8\"?><Flow><StartStream streamType=\"bidirectional\" streamUrl=\"wss://bot.example.com/stream\"></StartStream></Flow>"
  }'
```

Events: `stream_initiated`, `stream_started`, `stream_stopped`, `stream_failed`.

## Parallel greeting

### Start say

Same actions endpoint, with a `<Say>` verb. Optional attributes: `loop`, `language`, `preferredTTSEngine` (`polly` or `googletts`), `pollyVoiceId`, `googlettsVoiceName`. See [Say](/docs/exoml/verbs/say).

```bash
curl -u '<api_key>:<api_token>' -X POST \
  'https://cpaas-api.in.exotel.com/v2/accounts/<account_sid>/legs/<leg_sid>/actions' \
  -H 'Content-Type: application/json' \
  -d '{
    "exoml": "<?xml version=\"1.0\" encoding=\"UTF-8\"?><Flow><Say>Connecting you now.</Say></Flow>"
  }'
```

Events: `say_started`, `say_completed`, `say_interrupted`, `say_failed_to_start`.

### Stop say

```bash
curl -u '<api_key>:<api_token>' -X POST \
  'https://cpaas-api.in.exotel.com/v2/accounts/<account_sid>/legs/<leg_sid>/actions' \
  -H 'Content-Type: application/json' \
  -d '{
    "exoml": "<?xml version=\"1.0\" encoding=\"UTF-8\"?><Flow><StopSay></StopSay></Flow>"
  }'
```

Events: `say_interrupted` (stopped), `say_failed_to_stop`.
