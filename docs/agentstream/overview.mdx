# AgentStream

Stream live call audio to your bot over WebSocket — and send audio back for conversational Voice AI. Same bot protocol whether you dial via Connect API, App Bazaar flow, or ExoML Legs.

```
Caller ↔ Exotel ↔ wss://your-bot
```

## What you can build

| Capability | How |
|------------|-----|
| Outbound Voice AI | [Connect Voice AI](./connect-voice-ai) with `streamurl` + `streamtype=bidirectional` |
| Outbound + IVR / handoff | [Connect with Flow](./connect-voice-ai-flow) + Voicebot / Connect applets |
| Code-owned call control | [Programmable Voice (ExoML)](./programmable-voice) + `start_stream` |
| Listen-only / assist | [Stream applet](./stream-voicebot-applet) (unidirectional) |
| SIP ↔ bot bridge | [StreamKit Cloud](./streamkit-cloud) |
