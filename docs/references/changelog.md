## February 2026

### Feb 16, 2026 — Developer Documentation Upgrade

**New Features:**
- Interactive **API Console** ("Try It") on key API reference pages — test endpoints directly from the docs
- **Multi-language code tabs** with persistent language selection across pages
- **Error Code Dictionary** — centralized reference for all HTTP and application-level error codes
- **Webhooks & Callbacks Hub** — consolidated documentation for all webhook payloads
- **Changelog** page (this page)

**Improvements:**
- Copy button on all code blocks
- Consolidated navigation into 3 dropdown menus (APIs, Products, SDKs & Tools)
- Ask AI search powered by Anthropic for natural-language documentation queries

## Earlier Releases

### Voice v2 (CCM) API
- Agent-to-customer calling with user context
- Dual-channel recording support
- SIP URI and user ID based routing

### Voice v1 API
- Connect Two Numbers (click-to-call)
- Connect to Flow (IVR)
- Outgoing Call to Flow
- Number Metadata API
- StatusCallback webhooks

### SMS API
- Send SMS with DLT compliance
- Bulk SMS (static and dynamic)
- URL shortening for SMS links

### ExoPhones API
- Purchase, list, and manage virtual phone numbers
- Assign numbers to call flows

### Heartbeat API
- ExoPhone health monitoring
- Webhook-based alerts for connectivity issues
